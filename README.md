# 文字のデジタル化君

文字コードと2進数、データ量を見て・比べて・確かめる学習アプリです。

## 機能

- 全角・半角とも12文字まで入力
- ASCII／Shift_JISの文字コード（16進数）と2進数を表示
- 2進数から文字への復元
- バイト数・ビット数・文字数と、1文字ごとの内訳を表示
- 全角・半角を比べる入力例
- HTMLのダウンロード（ボタンを押したときだけ保存）

## 使い方

`index.html`をダウンロードして、Safari・Chrome・Edgeなどのブラウザで開きます。インストール不要です。必要な変換表はHTMLに含まれ、オフラインで動作します。入力データの外部送信、アクセス解析、外部ライブラリの読み込みはありません。アプリ内のGitHubリンクを開く場合のみ、リンク先へ移動します。

1. 文字から変換する場合は「文字 → 2進数」を選びます。
2. ASCIIまたはShift_JISを選び、文字を入力します。
3. 逆変換は「2進数 → 文字」で、0と1を入力します。8桁ずつ空白・改行で区切っても、そのまま連続して入力しても使えます。

ASCIIは日本語・全角文字に対応していません。Shift_JISも絵文字などには対応していません。未対応の文字はエラーとして表示し、別の文字に置換しません。

## 文字コードについて

- ASCIIは7ビットですが、本アプリでは先頭に0を付けて8桁で表示し、1文字1バイトとして数えます。
- JISのShift_JISを使用します。Windows-31Jの拡張文字は対象外です。
- 2バイト文字の16進数は2バイトをつないだコード値です。
- 0x5Cはバックスラッシュ、0x7Eはチルダとして扱います。
- データ量は文字そのものの量であり、ファイルの付加情報は含みません。
- 入力はUnicodeコードポイント単位で12文字まで。逆変換は24バイトかつ復元後12文字までです。

## GitHub Pagesで使う

リポジトリの **Settings → Pages** で、Sourceを **Deploy from a branch**、Branchを **main**、フォルダを **/(root)** にして保存します。公開後のURLはPages設定画面で確認できます。

公開URLをGoogleサイトの「挿入 → 埋め込む → URL」に指定したり、Google Classroomで配布したりできます。
